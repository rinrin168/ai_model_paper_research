# AI Research Paper Assistant Agent

An AI agent that helps students find, evaluate, and organize research sources. Built on Make.com and used through Telegram.

## How it works

1. The user sends a research topic to a Telegram bot.
2. Google Gemini understands the topic and writes a search query.
3. Tavily searches the web for candidate sources.
4. Gemini evaluates every source and marks it KEEP or REJECT.
5. If three or more sources are kept, the agent logs them in Google Sheets, saves a notes file to Google Drive, and replies with a short introduction and the full source list with links.
6. If fewer than three are kept, the agent instead suggests narrower topics and asks the user for more detail.

## Tools

Make.com, Google Gemini, Tavily Search API, Google Sheets, Google Drive, Telegram Bot API.
